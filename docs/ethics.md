# 使用边界与伦理说明 / Ethics and Boundaries

## 用途

本工具仅用于：

- 作者投稿前自查与修改规划；
- 学术写作与审稿训练、同行评议教学；
- 研究组内部的论文质量讨论。

## 禁止用途

- 冒充真实审稿人或伪造审稿意见提交到期刊/会议系统；
- 用于操纵、攻击或绕过真实同行评议流程；
- 编造引用、实验结果或录用概率；
- 声称与 Elsevier、TR-C 编辑部或任何官方编委会有关联。

## 已知局限

- 模拟审稿不能替代真实领域专家：可能漏掉技术硬伤、高估或低估创新性；
- 无文献检索时无法可靠识别具体漏引文献，只能指出缺失方向；
- 无法验证论文中证明的每一步推导或复现实验结果；
- 评分是"TR-C 风格模拟校准"，与真实审稿分数无统计对应关系。

## 对审稿材料的保密

用户上传的未发表论文属于保密材料。请在你所使用的 LLM 平台隐私政策允许的范围内使用本工具；涉及敏感或未公开成果时，优先使用本地或机构批准的模型环境。
